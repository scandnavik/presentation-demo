花了 200 萬
導 ERP，
還是回去用 Excel

一家台灣 30-80 人的半導體設備周邊廠商，導入 ERP 兩年，員工還是回去用各自的 Excel。

我們診斷出的根因

Open-source · 個人 Agent 平台

OpenClaw （社群俗稱「養龍蝦」）

2026 年起在 AI 圈紅起來的開源 agent 框架。讓個人玩家可以自己「養」一個或一群 agent，掛在自己電腦或雲端 24/7 跑。

▸ 用途：個人助理、研究員、自動化跑單
▸ 風險：龍蝦在自己水箱安全；對外開放就要顧 Prompt Injection
Open-source · Agent 自我演化

Hermes Agent （NousResearch）

不重訓模型，只演化 prompt 的方式讓 agent 自己變更聰明。意義是：不用每次換新模型，用對方法老模型也能進化。

▸ 技術：DSPy + GEPA 純 prompt 演化
▸ 啟示：未來公司的 AI 資產不是「買哪個模型」，是「累積出來的 prompt + 流程」
給二代的話：不是叫你去裝這些。是讓你知道「能力的天花板已經被打開」—— 接下來幾年，會有人把這些整合成真正能進工廠、進辦公室的服務。早一點看懂，對你做決定有用。

Act VI
Context Engineering · Agent 時代新核心

老闆問一句話 · 三條路

「台中區上季前 10 大客戶，應收還沒收回來的是誰？」

傳統 IT

寫 SQL · 1 天

你跟 IT 說需求 → IT 寫 SQL → 跑出 Excel → 寄給你。隔天才看得到。

ChatGPT

無能為力

ChatGPT 不知道你的客戶資料、不能連 ERP。它能教你 SQL，跑你還是要自己跑。

Agent + Context

問完即答

資料中台 + Agent 已經餵過公司資料、權限、業務規則。你問完它直接答。

Context Engineering = 把每個 Agent 該知道的事（公司資料、業務規則、權限、慣例）事先整理好餵給它。做完這件事 → ChatGPT 變成你的同事。沒做 → 永遠是個高級搜尋。

Act VI
Anatomy · 拆解一個 Agent 的 prompt

四件事 · 缺一不可

① 身份 · Identity　我是誰？例：「你是食安紀錄員，協助廠長盤點每日 HACCP 數據」
② 工具 · Tools　我能用什麼？例：「你可以查 Google Sheet 的紀錄表、可以推 LINE 給主管」
③ 約束 · Constraints　我絕對不做什麼？例：「不擅自下決策、不回答跟食安無關的問題」
④ 成功 · Success　怎樣算做好？例：「每日 100% 紀錄完成、異常 15 分鐘內 Tag 主管」
// food-safety-recorder.yaml
name: food-safety-recorder
role: HACCP 紀錄員
tools:
  - google-sheet
  - line-push
constraints:
  - never decide alone
  - only food safety
success:
  - daily 100% record
  - anomaly < 15min tag

四件事寫成 YAML 就是個 Agent 雛形。不是工程師才能寫，老闆自己描述就行。
